# XOLERIC Ustoz — Typing Practice

A **WPM (Words Per Minute)** typing practice app featuring 10 meaningful Uzbek-language topics with philosophical and educational texts. Designed to improve typing speed and accuracy in the Uzbek Latin alphabet.

## Features

- **10 Themed Topics** — Philosophical and educational texts in Uzbek
- **WPM Tracking** — Real-time words-per-minute and accuracy metrics
- **Virtual Keyboard** — On-screen Uzbek keyboard layout
- **PWA Support** — Installable, works offline via service worker
- **Character Highlighting** — Correct/incorrect visual feedback per character
- **Leaderboard Scores** — localStorage-based high scores per topic

## Tech Stack

- HTML5, CSS3 (dark theme, custom properties)
- Vanilla JavaScript
- PWA (Service Worker + Manifest)

## How to Run

```bash
# Serve locally:
python3 -m http.server 8080
# Open http://localhost:8080
```

Open `index.html` in any modern browser. No build step required.
